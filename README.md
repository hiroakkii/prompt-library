# プロンプトライブラリ

画像生成AI（NovelAI / PixAI）で使うプロンプトを管理し、「シチュエーション × キャラ」で組み立てるための、1ファイル完結のWebアプリです。

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

## 主な機能

| 画面 | できること |
|---|---|
| プロンプト | ポジ・ネガ・シチュエーション・キャラの一覧。検索（スペース区切りでAND）・並べ替え・お気に入り・使用回数・複数選択・一括削除（元に戻せる） |
| 絞り込み | 種別（ポジ／ネガ／シチュ／キャラ）、カテゴリ（複数選択）、タグ（複数選択・「すべて含む／いずれか」切り替え） |
| 組み立て | 一覧で選んだシチュエーションとキャラを表示・調整し、NovelAI / PixAI 用に出力 |
| 設定 | NovelAIの重み書式・刻み・区切り文字、人数タグの自動付与、重複タグの除去、括弧のエスケープ、カテゴリの名前変更・削除、全置換前の状態への復元 |

### 画面の配置

- スマホ：画面下のタブで「プロンプト」「絞り込み」「組み立て」を切り替えます。
- PC（幅1100px以上）：左に一覧（または絞り込み）、右に組み立てを常に並べて表示します。
- 色は種別を表します（ポジ＝藍、ネガ＝紅、シチュエーション＝青緑、キャラ＝琥珀）。一覧の左端の色帯、チップ、組み立ての各ブロックの上端で同じ色を使います。
- 画面の文字は Google Fonts の Zen Kaku Gothic New を使います。読み込めない環境では端末の標準フォントで表示します。

## 登録と組み立ての考え方

「新規追加」で、次の4種類を登録できます。どれも同じ一覧に並び、検索・絞り込み・お気に入りが使えます。

| 種別 | 登録する内容 | 一覧でクリックすると |
|---|---|---|
| ポジ / ネガ | 1つのプロンプト（タグか文章） | 組み立て中の「追加先」に入る（ネガは常にネガティブへ） |
| 表情 | 1つのプロンプト（表情のタグ） | 選択中のキャラ枠の「表情」に入る（キャラ枠が無ければ作る） |
| シチュエーション | ベース（ポジ）とネガティブを同時に | 組み立てタブに読み込む |
| キャラ | 性別・外見・服装 | 選択中のキャラ枠に入る（枠が無ければ作る） |

登録したあとでも、編集画面で種別を変えられます（種別の変換）。

- 元の内容は新しい種別の欄に移します（例：ポジ → シチュエーションならベースへ、ネガ → シチュエーションならネガティブへ、ポジ → キャラなら外見へ）。
- 引き継げない内容（シチュエーション → ポジのときのネガティブ、キャラ枠ごとの状態、性別など）がある場合や、その項目を使っているチップとのつながりが切れる場合は、保存前に1回だけ警告します。チップの内容自体は残ります。
- 変換は直後なら「元に戻す」で取り消せます。ポジ ⇔ ネガの切り替えは警告なしです。
- 一覧で複数の項目を選び、「種別を変換」でまとめて変換することもできます（キャラに変換するときは性別も選べます）。警告は1回だけで、直後なら元に戻せます。
- 組み立てタブの「一覧から選ぶ」は、検索・カテゴリ・タグの条件を外して、種別だけで絞り込みます。その種別の項目が1件もないときは、変換の方法と、該当しそうなカテゴリの項目を表示するボタンを案内します。

シチュエーションとキャラの入力欄では、1行ごとにカンマ区切りのタグか文章を書きます（文章は文末を `.` で終える）。重みは `(tag:1.2)` で書けます。

```
組み立て ＝ シチュエーション 1つ ＋ キャラ（NovelAI 最大22人／PixAI 最大6人）
```

- シチュエーションには、キャラそのものではなく「そのシーンでのキャラの状態」を枠ごとに登録できます（新規追加・編集画面の「キャラ枠ごとの状態」）。
  - 組み立てタブの「表情」欄では、「表情から選ぶ」で種別「表情」のプロンプトを一覧から選べます（検索でき、押すたびに入れる／外すが切り替わり、続けて選べます）。シチュエーションに登録した表情もそのまま入り、チップの × で1つずつ、「消去」ですべて外せます。
  - 各枠に、状態（ポーズ・動作タグなど）、表情、想定の性別を書きます。表情は状態とは別の欄で、出力では状態の後ろ（セリフの前）に入ります。組み立てタブでも「表情」欄に一覧から追加でき、状態と同じく上書き保存で登録内容に入ります。
  - 各枠にはセリフと「吹き出しにする」も登録できます。シチュエーションを読み込むと、登録したセリフが各キャラ枠のセリフ欄に入ります。組み立てタブで書き換えたセリフは、上書き保存・別件として保存をしても登録内容には入りません（登録したセリフは編集画面で変えます。「元に戻す」で登録したセリフに戻ります）。セリフは JSON に含まれ、取り込み時も枠ごとに取り込まれます。
  - 一覧でシチュエーションを読み込むと、登録した枠の数だけ空のキャラ枠が用意されます。あとは一覧でキャラをクリックして入れるだけです。
  - キャラが未選択の枠も、状態だけで出力されます（NovelAI では「キャラN（未選択）」の欄）。人数タグは想定の性別から作ります。キャラを入れたときはキャラの性別を優先します。
  - 未選択の枠を状態だけで出力しているときは、出力欄の上に警告を出し、該当する出力欄に「キャラ未選択を含む」の印を付けます。その欄をコピーしたときや .txt で保存したときも、未選択の枠があることを知らせます。
  - 組み立てタブで枠の × を押すと、その枠の状態も外れ、以降の枠が1つずつ前に詰まります（「元に戻す」で登録内容に戻せます）。
- 組み立てタブの各キャラ枠には「セリフ」欄があります。吹き出しに出すセリフを直接入力すると、そのキャラ欄の**最後**に入ります。
  - NovelAI：`speech bubble, Text: セリフ`（`Text:` より後ろはセリフとして扱われるため、必ず最後に置きます）
  - PixAI：`speech bubble, "セリフ"`（Tsubaki.3 の決まった書き方は確認できていないため、引用符で囲む形にしています）
  - 「吹き出しにする」は最初からオンです。オフにすると `speech bubble` を付けません。
  - セリフは**その場限り**で、シチュエーションやキャラの登録内容には保存しません（上書き保存しても入りません）。組み立て中の状態としては残るので、アプリを開き直しても消えません。枠の × や一括削除で消えます。
  - 重複除去・括弧のエスケープ・カンマでの分割の対象外です。NovelAI の文字数の目安（V5 Curated 374 文字、V5 Full 750 文字）を超えると注意を出します。品質タグの `no text` の影響で短いセリフが出ないことがあります。
- 連続したシーン（開始・継続・終了など）は**フォルダ**にまとめられます（シチュエーションの新規追加・編集画面の「フォルダ」）。
  - 同じフォルダ名のシチュエーションは、一覧で1つのフォルダ行にまとまります。行をクリックすると開閉し、中のシーンが順番どおりに並びます。順番は ↑↓ で入れ替えます。
  - 検索すると、条件に合うシーンがあるフォルダは自動で開きます。フォルダ名でも検索できます。フォルダ行のチェックで、中のシーンをまとめて選べます。✎ でフォルダ名を変えられます（既存のフォルダ名にするとまとめられます）。
  - フォルダのシーンを組み立てに読み込むと「フォルダ〇〇　シーン 1 / 3」と表示され、「次のシーンを選ぶ」から同じフォルダの別のシーン（差分も含む）に切り替えられます。切り替えてもキャラ枠はそのままで、セリフは切り替え先のシーンに登録したセリフに入れ替わります（登録がなければ空になります）。
  - 同じメニューの「今のシーンを複製して、このフォルダに追加」で、今のシーンの直後に新しいシーンを作れます。「別件として保存」も、元のシーンの直後に入ります。
  - フォルダに入れていないシチュエーションは、今までどおり1件ずつ表示します。フォルダはJSONに含まれ、取り込み画面でもフォルダごとに並びます（Excel / CSV では「フォルダ」「順番」列）。
- 組み立てタブに読み込んだ内容は**作業用のコピー**です。重みの変更や項目の追加はその場限りで、登録内容は変わりません。
  - 変更があると「未保存の変更」と表示されます。
  - 「上書き保存」：登録内容を、いまの組み立て内容で置き換えます（直後なら元に戻せます）。
  - 「別件として保存」：新しいシチュエーション（キャラ）として登録します。
  - 「元に戻す」：登録内容を読み直します。
  - 未保存の変更があるときに別のシチュエーションやキャラを読み込むと、破棄してよいか確認します。
- シチュエーションを固定したまま、キャラ枠のキャラだけを入れ替えられます。
- 「シチュエーションとキャラを一括削除」で、組み立て中のシチュエーションとキャラ枠をまとめて外せます（確認は1回。一覧の登録内容は消えません）。
- 「キャラ枠ごとの状態」は**枠の番号**に付きます。`source#hug` をキャラ1の枠に、`target#hug` をキャラ2の枠に入れておけば、誰を入れても役割は変わりません。
- シチュエーションで「キャラの服装を使わない」をオンにすると、キャラの服装を出さずに、シチュエーション側の服装だけを使えます。
- チップは長押し（PCはドラッグ）で、並べ替えや、別の欄（ベース⇔外見など）への移動ができます。

### 出力

| 出力先 | 出力される欄 | 重みの書式 |
|---|---|---|
| NovelAI | ベースプロンプト ／ キャラ1〜n ／ 除外したい要素 | `1.20::word::`（または括弧の重ね `{word}`） |
| PixAI | プロンプト（ベース → キャラ1 → キャラ2 …を1本に。区切り文字か改行段落でつなぐ） ／ ネガティブ | `(word:1.20)` |

- 人数タグの自動付与（初期値オン）：ベースの先頭に、選んだキャラの性別から `2girls, 1boy` などを付けます。このとき、ベースにもともとある人数タグは置き換えます。NovelAIでは、キャラ欄の先頭にも `girl` / `boy` を付けます。性別が「その他」のキャラは数えません。
- PixAIでは全キャラのタグが1本にまとまるため、どのタグがどのキャラに効くかは指定できません。
- 「まとめてコピー」で、すべての出力を「.txtで保存」と同じ形（`## 欄の名前` の見出し付き）でコピーできます。
- 「コピーして〇〇を開く」で、まとめてコピーしてから指定したサイト・アプリを新しいタブで開きます。開く先は設定画面の「コピーして開く先」（1行に `名前 | URL`、最大10件）で変えられます。最初は NovelAI・PixAI・Muse です。
  - `https://` のほか、アプリ独自のURL（`appname://…`）も使えます。`javascript:` などは使えません。
  - スマホでは、相手のアプリがユニバーサルリンクに対応していれば、Safari ではなくアプリが開きます（Muse アプリが受け付けるのは `https://muse.ai/chat` などのページで、トップページ `https://muse.ai/` では Safari が開きます。初期値は `/chat` にしてあり、トップページのまま保存されていた設定も自動で `/chat` に直します）。アプリが開かない場合は、iPhone の「ショートカット」アプリで「アプリを開く」ショートカットを作り、`shortcuts://run-shortcut?name=ショートカット名` を開く先に登録すると確実に開けます。Claude アプリの中で使っている場合は、外部を開く動作が制限されることがあります。
  - 開いた先の入力欄には、自分で貼り付けてください（相手のアプリの入力欄に自動で入れることはできません）。
- キャラ数の上限：NovelAI は V5 の公式上限に合わせて22人です（実際に安定する人数はもっと少ないことがあります）。PixAI は1本にまとまるので6人までで、それより多い枠があるときは先頭6人だけ出力します。
- トークン数は概算です（実際のトークナイザーとは多少ずれます）。

### タグと文章（自然言語）

PixAI Tsubaki.3 のように文章での入力が向いているモデルに対応するため、ライブラリの各項目を「文章」として登録できます（編集画面のチェック、または Excel の `形式` 列に「文章」と書く）。

- 文章の項目はカンマで分割しないので、重複除去・括弧のエスケープ・人数タグの置き換えの対象になりません。
- 文末（`.` など）のあとにはカンマを付けず、スペースでつなぎます。
- 設定「PixAI でのベースとキャラのつなぎ方」を「改行で段落に分ける」にすると、ベースとキャラごとの描写が段落に分かれます。
- タグと文章は混ぜて使えます（例：先頭にタグ、続けて場面の描写）。

## 訳の辞書（タグの日本語訳）

英語のタグの意味が分からなくても使えるように、タグごとの日本語訳を辞書にためて、画面では日本語を主に、英語を小さく添えて表示します。アプリの中で機械翻訳はしません。訳は「Muse が JSON に付ける」「自分で書く」「辞書ファイルを取り込む」のどれかで入ります。

- 訳は**タグごと**に1か所の辞書（`plib.dict.v1`）に持ちます。キーは小文字・`_` を空白にそろえたタグ、値は最大60文字、上限は20,000件です。チップ自体には訳を保存しません。
- 組み立てタブのチップは、日本語が主・英語が小さな添え字です。訳のないタグは英語のまま、点線の下線で区別します。表示名を付けたチップは、その表示名が主になります。
- チップをタップ（クリック）すると、操作パネルが開きます（くわしくは「スマホでの操作」）。パネルの下半分が訳の欄で、日本語の訳を書くと辞書に保存され、同じタグを使うほかのチップ・一覧の行にも反映されます（空にすると辞書から消えます）。「Google 翻訳で開く」「Danbooru の解説を開く」のリンクもあります。ドラッグや − ＋ ×、長押しでの並べ替えではパネルは開きません。
- 一覧の行には、英語の上に訳の行を出します。検索は訳にも当たります（「銀髪」で `silver hair` を含む項目が見つかります）。
- 出力ブロックの「訳を表示」をオンにすると、各出力欄の下に訳した文を出します。**コピーされる内容（出力欄・まとめてコピー・.txt）は英語のままで、辞書の有無で変わりません。**
- 設定画面の「訳の辞書」から、辞書の一覧・編集（検索、すべて／未訳だけ）、書き出し（`prompt-dict-日時.json`）、辞書ファイル（`.json` / `.csv` / `.tsv` / `.txt`）の取り込みができます。5,000件を超えるファイルは、一覧で使っているタグに当たる分だけ取り込みます。
- 「未訳のタグをコピー」は、一覧にあって辞書にないタグ（最大300個）を、Muse に訳してもらうための依頼文としてコピーします。返ってきた JSON（```json の囲み付きでも可）や、`tag = 訳` の行を「訳を貼り付けて取り込む」に貼ると、辞書に入ります（この取り込みは既存の訳を上書きします）。
- 「書き出し」メニューの「Muse への依頼文をコピー」で、訳つきのプロンプトを JSON で作ってもらうための依頼文をコピーできます。
- 取り込む JSON には、次を付けられます（どれも任意）。取り込むと辞書に**足されます**（すでにある訳は残し、件数をトーストで知らせます）。古い JSON もそのまま読めます。
  - トップレベルの `dict`：`{"silver hair":"銀髪"}`
  - チップの `ja`：`{"text":"silver hair","ja":"銀髪"}`。ポジ・ネガ・表情の項目の `ja` も同じです。`text` が複数のタグのときは、`ja` を `、` か `,` で分けた数が同じなら1対1で対応させます。
  - チップは文字列でも書けます（`"silver hair"`）。
- JSON バックアップには `dict` が入ります。全置換の「元に戻す」で、辞書も戻ります。

## スマホでの操作

幅720px以下の画面では、指で押しやすいように次の点が変わります。PC（幅721px以上）の見た目と操作は変わりません（チップの操作パネル、順番コピー、「貼り付けて取り込む」は PC でも使えます）。

- **チップの操作パネル**：チップのラベルをタップ（PCはクリック）すると、パネルが開きます。上から、チップの名前（日本語、なければ英語）と英語の全文、重みの「−」「値」「＋」「1.0 に戻す」（刻みは設定の「重みの刻み」、範囲 0.1〜2.0）、タグごとの訳、「このチップを外す」です。重みを変えても開いたままで、出力にすぐ反映されます。
  - スマホでは画面下のシート（高さは画面の7割まで、右上の「閉じる」か外側のタップで閉じます）、PCではチップの近くに浮かびます。同じチップをもう一度押す・Esc・外側のクリックでも閉じます。
  - スマホではチップの − ＋ は隠れます（重みはパネルで変えます）。× は押せる範囲を広げています。
- **一覧タブの上部**：検索と「⋯」メニュー、種別の行（絞り込みタブの種別ボタンと同じ状態）、追加先の1行にまとまります。「⋯」には、取り込み（ファイル）・貼り付けて取り込む・書き出し・並べ替え・表示中をすべて選択・設定と、登録件数が入っています。新規追加は右下の丸い「＋」ボタンです（一覧タブだけに出ます）。
- **行の「⋯」**：★ ✎ 🗑 の代わりに、お気に入り・編集・削除（元に戻せます）を開きます。フォルダ内のシーンには「前へ」「後ろへ」も入ります。
- **順番コピー**：組み立てタブの下端（PCは右の組み立て欄の下端）に、出力欄の名前（ベース・キャラ1…・ネガ。PixAI はプロンプト・ネガ）を並べたバーが出ます。「次をコピー」でまだコピーしていない最初の欄をコピーし、✓ が付きます。名前を押すとその欄だけをコピーします。「最初から」で ✓ が外れます。出力の中身が変わった欄の ✓ は自動で外れます（進み具合は保存しません）。コピーされる文字列は、出力欄と同じです。出力がすべて空のときは出ません。

## 取り込み・書き出し

- **Excel / CSV**：1行目の見出し（`カテゴリ` `表示名` `プロンプト` `タグ` `メモ` `種別` `形式` `ネガティブ` `服装` `性別`）で列を判定します。見出しが無い場合は、先頭7列（カテゴリ〜形式）の順で読み取ります。タグは `,` か `、` で区切ります。
  - `種別` が「シチュ」の行は、`プロンプト` をベース、`ネガティブ` をネガティブとして読みます。
  - `種別` が「キャラ」の行は、`プロンプト` を外見、`服装` を服装、`性別` を性別として読みます。
  - キャラ枠ごとの状態と「服装を使わない」の設定は、Excel / CSV には含まれません（JSON には含まれます）。
- **JSON**：バックアップの保存・復元用です（形式 v3）。全置換すると、組み立て中の状態も復元されます。旧形式（v1 / v2）のバックアップも読み込めます。その場合、シチュエーションとキャラは一覧の項目に変換されます。
- **貼り付けて取り込む**：Muse の返答（JSON）を、ファイルに保存せずに取り込めます。「取り込み」の隣の「貼り付けて取り込む」（スマホは「⋯」メニュー）で入力欄に貼り付け、「読み取る」を押します。```json の囲みや前後の説明文が付いていても読み取れます。読み取れたら、ファイルの JSON と同じ取り込み画面が開きます。読み取れないときは、貼り付けた内容を残したままお知らせします。
- 取り込み（JSON・Excel・CSV 共通）では、読み込んだ項目を一覧で表示し、取り込むものを選べます。
  - 種別での絞り込み、表示名・カテゴリ・内容での検索、「表示中をすべて選ぶ」「表示中の選択を外す」が使えます。
  - いま登録されている項目（またはファイル内の前の項目）と同じ内容のものは「登録済み」と表示し、最初は選ばれていません。選んで追加すると重複して登録されます。
  - 「選んだ項目を追加」は、選んだ項目だけを追加します。ファイル内のシチュエーション・キャラが使っているチップと元の項目のつながりも引き継ぎます。
  - 「選んだ項目で全置換」は、選んだ項目だけでいまのデータを置き換えます。JSON に含まれる組み立て中の状態（シチュエーション・キャラ枠・セリフなど）は、全置換のときだけ復元します。
- 「全置換」は直後のトーストから元に戻せます。設定画面の「全置換する前の状態に戻す」からも復元できます。
- Excel機能（SheetJS）は、取り込み・書き出しをしたときに読み込みます。まず公式CDNの最新版を読み込み、読み込めない環境（Claudeアプリ内など）では jsDelivr の 0.18.5 を SRI 付きで使います。

## データの保存先

起動した環境に応じて、自動で選びます。

1. Claudeアプリ内の保存領域（`window.storage`）
2. ブラウザの localStorage
3. どちらも使えない場合はメモリのみ（画面上部に警告が出ます）

念のため、定期的に「書き出し」→「JSON バックアップを保存」で手元にバックアップを残してください。

## 開発メモ

- 変更は `index.html` を直接編集し、内容が分かるコミットメッセージを付けてコミットしてください（GitHub上で「削除→アップロード」を繰り返すと、差分の履歴が追えなくなります）。
- 保存キー：`plib.library.v1`（一覧の全項目・カテゴリ）、`plib.compose.v3`（組み立て中の作業用コピー）、`plib.config.v1`（設定）、`plib.prereplace.v1`（全置換前のバックアップ）、`plib.premigrate.v3`（形式移行前のデータ）、`plib.dict.v1`（訳の辞書）
- 旧形式のデータ（`plib.compose.v2` のシチュエーション・キャラ、`plib.memos.v1` のメモ欄タブ）は、`plib.compose.v3` が無い場合だけ、初回起動時に一覧の項目へ移します。旧データは消さずに残し、移行前のデータは設定画面からJSONで保存できます。

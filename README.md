# プロンプトライブラリ

画像生成AI（Stable Diffusion / ComfyUI / NovelAI など）で使うプロンプトを管理・組み立てるための、1ファイル完結のWebアプリです。

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

## 主な機能

| 画面 | できること |
|---|---|
| プロンプト | 一覧・検索（スペース区切りでAND）・並べ替え・お気に入り・使用回数・複数選択・一括削除（元に戻せる） |
| 絞り込み | ポジ／ネガ、カテゴリ（複数選択）、タグ（複数選択・「すべて含む／いずれか」切り替え） |
| メモ欄 | シーンごとのタブで組み立て。重み調整、長押し（PCはドラッグ）で並べ替え・ポジ⇔ネガ移動、出力のコピー／.txt保存 |
| 設定 | 重みの書式・刻み・区切り文字、重複タグの除去、括弧のエスケープ、カテゴリの名前変更・削除、全置換前の状態への復元 |

### 出力の書式

| 設定 | 例 | 対象 |
|---|---|---|
| `(word:1.20)` | `(silver hair:1.20)` | A1111 / Forge / ComfyUI |
| `1.20::word::` | `1.20::silver hair::` | NovelAI V4 |
| `{word}` / `[word]` | `{{{{silver hair}}}}` | NovelAI（括弧の重ね、1段 ≒ ×1.05） |
| 重みなし | `silver hair` | — |

「全文コピー（A1111形式）」は `ポジティブ` + 改行 + `Negative prompt: ネガティブ` の形でコピーします。
トークン数は概算です（実際のトークナイザーとは多少ずれます）。

## 取り込み・書き出し

- **Excel / CSV**：1行目の見出し（`カテゴリ` `表示名` `プロンプト` `タグ` `メモ` `種別`）で列を判定します。見出しが無い場合は、この列順で読み取ります。タグは `,` か `、` で区切ります。
- **JSON**：バックアップの保存・復元用です。全置換するとメモ欄のタブも復元されます。
- 「全置換」は直後のトーストから元に戻せます。設定画面の「全置換する前の状態に戻す」からも復元できます。
- Excel機能（SheetJS）は、取り込み・書き出しをしたときに読み込みます。まず公式CDNの最新版を読み込み、読み込めない環境（Claudeアプリ内など）では jsDelivr の 0.18.5 を SRI 付きで使います。

## データの保存先

起動した環境に応じて、自動で選びます。

1. Claudeアプリ内の保存領域（`window.storage`）
2. ブラウザの localStorage
3. どちらも使えない場合はメモリのみ（画面上部に警告が出ます）

念のため、定期的に「書き出し」→「JSON バックアップを保存」で手元にバックアップを残してください。

## 開発メモ

- 変更は `index.html` を直接編集し、内容が分かるコミットメッセージを付けてコミットしてください（GitHub上で「削除→アップロード」を繰り返すと、差分の履歴が追えなくなります）。
- 保存キー：`plib.library.v1`（プロンプト・カテゴリ）、`plib.memos.v1`（メモ欄）、`plib.config.v1`（設定）、`plib.prereplace.v1`（全置換前のバックアップ）

# プロンプトライブラリ

画像生成AI（NovelAI / PixAI）で使うプロンプトを管理し、「シチュエーション × キャラ」で組み立てるための、1ファイル完結のWebアプリです。

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

## 主な機能

| 画面 | できること |
|---|---|
| プロンプト | 素材（ライブラリ）の一覧・検索（スペース区切りでAND）・並べ替え・お気に入り・使用回数・複数選択・一括削除（元に戻せる）。クリックで「追加先」に入る |
| 絞り込み | ポジ／ネガ、カテゴリ（複数選択）、タグ（複数選択・「すべて含む／いずれか」切り替え） |
| 組み立て | シチュエーションとキャラを選んで、NovelAI / PixAI 用に出力 |
| 設定 | NovelAIの重み書式・刻み・区切り文字、人数タグの自動付与、重複タグの除去、括弧のエスケープ、カテゴリの名前変更・削除、全置換前の状態への復元 |

## 組み立ての考え方

```
シチュエーション（保存）  ベース ／ ネガティブ ／ キャラ枠ごとの追加（動作タグ・表情など）
キャラ（保存）           性別 ／ 外見 ／ 服装
組み立て                 シチュエーション 1つ ＋ キャラ（NovelAI 最大22人／PixAI 最大6人）
```

- シチュエーションを固定したまま、キャラ枠のキャラだけを入れ替えられます。
- 「キャラ枠ごとの追加」は**枠の番号**に付きます。`source#hug` をキャラ1の枠に、`target#hug` をキャラ2の枠に入れておけば、誰を入れても役割は変わりません。
- シチュエーションで「キャラの服装を使わない」をオンにすると、キャラの服装を出さずに、シチュエーション側の服装だけを使えます。
- 一覧で項目をクリックすると「追加先」（画面上部に表示）に入ります。ネガの項目は、常にシチュエーションのネガティブに入ります。
- チップは長押し（PCはドラッグ）で、並べ替えや、別の欄（ベース⇔外見など）への移動ができます。

### 出力

| 出力先 | 出力される欄 | 重みの書式 |
|---|---|---|
| NovelAI | ベースプロンプト ／ キャラ1〜n ／ 除外したい要素 | `1.20::word::`（または括弧の重ね `{word}`） |
| PixAI | プロンプト（ベース → キャラ1 → キャラ2 …を1本に。区切り文字か改行段落でつなぐ） ／ ネガティブ | `(word:1.20)` |

- 人数タグの自動付与（初期値オン）：ベースの先頭に、選んだキャラの性別から `2girls, 1boy` などを付けます。このとき、ベースにもともとある人数タグは置き換えます。NovelAIでは、キャラ欄の先頭にも `girl` / `boy` を付けます。性別が「その他」のキャラは数えません。
- PixAIでは全キャラのタグが1本にまとまるため、どのタグがどのキャラに効くかは指定できません。
- キャラ数の上限：NovelAI は V5 の公式上限に合わせて22人です（実際に安定する人数はもっと少ないことがあります）。PixAI は1本にまとまるので6人までで、それより多い枠があるときは先頭6人だけ出力します。
- トークン数は概算です（実際のトークナイザーとは多少ずれます）。

### タグと文章（自然言語）

PixAI Tsubaki.3 のように文章での入力が向いているモデルに対応するため、ライブラリの各項目を「文章」として登録できます（編集画面のチェック、または Excel の `形式` 列に「文章」と書く）。

- 文章の項目はカンマで分割しないので、重複除去・括弧のエスケープ・人数タグの置き換えの対象になりません。
- 文末（`.` など）のあとにはカンマを付けず、スペースでつなぎます。
- 設定「PixAI でのベースとキャラのつなぎ方」を「改行で段落に分ける」にすると、ベースとキャラごとの描写が段落に分かれます。
- タグと文章は混ぜて使えます（例：先頭にタグ、続けて場面の描写）。

## 取り込み・書き出し

- **Excel / CSV**：1行目の見出し（`カテゴリ` `表示名` `プロンプト` `タグ` `メモ` `種別` `形式`）で列を判定します。見出しが無い場合は、この列順で読み取ります。タグは `,` か `、` で区切ります。
- **JSON**：バックアップの保存・復元用です（形式 v2）。全置換すると、シチュエーションとキャラも復元されます。旧形式（v1）のバックアップも読み込めます。その場合、メモ欄のタブはシチュエーションに変換されます。
- 「全置換」は直後のトーストから元に戻せます。設定画面の「全置換する前の状態に戻す」からも復元できます。
- Excel機能（SheetJS）は、取り込み・書き出しをしたときに読み込みます。まず公式CDNの最新版を読み込み、読み込めない環境（Claudeアプリ内など）では jsDelivr の 0.18.5 を SRI 付きで使います。

## データの保存先

起動した環境に応じて、自動で選びます。

1. Claudeアプリ内の保存領域（`window.storage`）
2. ブラウザの localStorage
3. どちらも使えない場合はメモリのみ（画面上部に警告が出ます）

念のため、定期的に「書き出し」→「JSON バックアップを保存」で手元にバックアップを残してください。

## 開発メモ

- 変更は `index.html` を直接編集し、内容が分かるコミットメッセージを付けてコミットしてください（GitHub上で「削除→アップロード」を繰り返すと、差分の履歴が追えなくなります）。
- 保存キー：`plib.library.v1`（プロンプト・カテゴリ）、`plib.compose.v2`（シチュエーション・キャラ・組み立て状態）、`plib.config.v1`（設定）、`plib.prereplace.v1`（全置換前のバックアップ）
- 旧 `plib.memos.v1`（メモ欄のタブ）は、`plib.compose.v2` が無い場合だけ、初回起動時にシチュエーションへ移します。旧データは消さずに残します。

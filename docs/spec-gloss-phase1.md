# 仕様書：タグの日本語訳（第1回・訳の土台）

設計：Fable 5.2 ／ 実装：Sonnet 5.5。この文書だけを読んで実装できるように書いています。

## 背景と目的

- このアプリ（`index.html` 1ファイル）は、画像生成AI（NovelAI / PixAI）用のプロンプトを管理し、スマートフォンでコピー＆ペーストして使います。
- プロンプトは Muse（Meta の AI エージェント）に英語のタグで作ってもらい、JSON で取り込みます。
- 利用者は英語のタグの意味が分かりません。**タグごとの日本語訳を辞書としてためて、画面では日本語を主に、英語を小さく添えて表示**します。
- アプリ内で機械翻訳はしません。訳は「Muse が JSON に付ける」「利用者が書く」「辞書ファイルを取り込む」のどれかで入ります。

## 決定事項（変えないこと）

1. 訳は**タグごと**に持つ（例：`silver hair` → `銀髪`）。
2. チップは**日本語が主、英語が小さく添え字**。訳がないタグは英語のまま表示し、点線の下線で区別する。
3. **コピーされる出力（textarea の中身、まとめてコピー、.txt）は英語のまま変えない。**
4. 訳の保存先は辞書1か所だけ。チップ自体には訳を保存しない（取り込み時に辞書へ吸収する）。

## データ

### 辞書 `S.dict`
- 形：`{ "<キー>": "<日本語>" }` のオブジェクト。
- キー：既存の `tokKey(tag)`（エスケープ除去、`_`→空白、空白の正規化、小文字化）の結果。空のキーは入れない。
- 値：前後の空白を除いた文字列、最大60文字。空なら登録しない（＝削除）。
- 保存キー：`plib.dict.v1`（`K_DICT`）。`doSave()` で保存、起動時の `Promise.all` に読み込みを追加。
- JSON バックアップ（`backupJSON`）に `dict` を含める。`snapshot()` / `restoreSnap()` にも含める（全置換の取り消しで辞書も戻る）。
- 上限：20,000 件。超える分は入れず、件数をトーストで知らせる。

### 辞書を引く関数
```js
glossOf(tag)        // 1タグの訳。なければ ""
glossTokens(text,nl)// [{en, ja}] を返す。nl（文章）のときは全体を1つとして引く。
                    // それ以外は splitTop(text) で分け、各タグを引く。
                    // (tag:1.2) の形は外側を外して中身で引く（textToChips と同じ正規表現）。
glossText(text,nl)  // 表示用の文字列。訳があるタグは日本語、ないタグは英語のまま、"、" でつなぐ
hasFullGloss(text,nl) // すべてのタグに訳があれば true
```

### 取り込みで訳を受け取る形（すべて任意）
既存の JSON 形式に、次を追加で受け付けます。どれも `upgrade()` の前後で辞書候補として集め、`applyImport()` の実行時に辞書へ入れます（追加・全置換のどちらでも、**辞書は置き換えずに足す**）。

1. トップレベルの `dict`：`{"silver hair":"銀髪", ...}`
2. チップの `ja`：`{"text":"silver hair","ja":"銀髪"}`
   - チップの `text` が複数タグ（`"beach, sunset"`）で、`ja` を `、` か `,` で分けた数が同じなら、1対1で対応させる。数が違えば、全体を1つのキーとして入れる。
   - `nl:true`（文章）のチップは全体を1つのキーとして入れる。
3. ポジ・ネガ・表情の項目の `ja`：2 と同じ規則で、`text` に対応させる。
4. チップは**文字列でも受け付ける**（`"silver hair"` → `{text:"silver hair"}`）。`normChip` を、文字列が来たらチップに直すように変える。

辞書に同じキーがすでにある場合は、**既存の訳を残す**（利用者が直した訳を守るため）。飛ばした件数を数え、取り込み後のトーストに「訳 N 件を辞書に追加（すでにある M 件はそのまま）」と添える。訳が1件もないときは何も添えない。

書き出すチップには `ja` を付けない（辞書が `dict` として一緒に出るため）。

## 画面

### 1. チップ（組み立てタブ）
`chipHTML(c,k)` を変える。

- 主の表示：`c.name` があればそれ（利用者が付けた表示名）。なければ `glossText(c.text,c.nl)`。
- 添え字（英語）：主の表示が `c.text` と違うときだけ、`c.text` を小さく出す。
- 訳がそろっていない（`c.name` がなく、`hasFullGloss` が false）チップは、クラス `nogloss` を付け、主の表示に点線の下線。
- 見た目：
  ```
  ┌──────────────────────┐
  │ 銀髪          − ＋ × │   ← 主：13px、var(--sans)
  │ silver hair          │   ← 添え字：10.5px、var(--mono)、var(--ink3)
  └──────────────────────┘
  ```
  ラベル部分を縦2段（`.cl` の中に `.cn` と `.ce`）にする。どちらも1行で、あふれたら `…`。幅の上限は今の `.cn` と同じ（PC 220px、スマホ 150px）。添え字がないチップは今と同じ高さ。
- `title` 属性は今のまま英語の全文。

### 2. チップをタップ → 訳の小窓
- チップのラベル部分（ボタン以外）を**ドラッグせずに**クリック／タップしたら、小窓（`#glossPop`、既存の `.menu` と同じ作り）を開く。
- 中身：タグごとに1行。英語（等幅）と、日本語の入力欄（`placeholder="日本語の訳"`）。その下に「Google 翻訳で開く」「Danbooru の解説を開く」のリンク（新しいタブ、`rel="noopener noreferrer"`）。
  - Google 翻訳：`https://translate.google.com/?sl=en&tl=ja&op=translate&text=` + `encodeURIComponent(tag)`
  - Danbooru：`https://danbooru.donmai.us/wiki_pages/` + `encodeURIComponent(tag の空白を _ にしたもの)`
  - 文章（nl）のチップは Google 翻訳のリンクだけ。
- 入力欄は `change` で辞書に保存し、`render()` と `save()`。空にしたら辞書から削除。
- 外側をクリックで閉じる。Esc でも閉じる。
- ドラッグ（マウスは6px以上の移動、タッチは長押し）を始めたときは開かない。ドラッグ直後のクリックでも開かないこと（`dragFinish` 後の click を1回無視するなど）。
- 既存の − ＋ × ボタン、長押しでの並べ替えは今のまま動くこと。

### 3. 一覧（プロンプトタブ）
`rowHTML` を変える。

- ポジ・ネガ・表情の項目：`.rtext`（英語）の**上**に、訳の行 `.rgloss` を出す（`glossText(p.text,p.nl)`、13px、var(--sans)、var(--ink)）。訳が1つもないときは出さない。英語の `.rtext` は今のまま残す。
- シチュエーション・キャラ：`summary(p)` と同じ並びで、チップを `glossText` に通した訳の行を出す（`summaryGloss(p)` を作る）。訳が1つもないときは出さない。
- 取り込み画面の一覧（`renderImp`）は変えなくてよい。

### 4. 検索
`hayOf(p)` に訳を含める。ポジ・ネガ・表情は `glossText(p.text,p.nl)`、シチュエーション・キャラは `summaryGloss(p)`。これで「銀髪」で検索すると `silver hair` を含む項目が見つかる。

### 5. 出力欄の訳表示
- 出力ブロックの見出し行（「まとめてコピー」の左）に、チェック「訳を表示」を置く。状態は `S.cfg.showGloss`（初期値 true）に保存。
- オンのとき、各出力欄の textarea の**下**に、訳した文を1段落で出す（`.outGloss`、13px、var(--ink2)）。元にするのは `b.a.plain`（重み記法を除いたテキスト）。`Text: …` のセリフ部分と `speech bubble` などは、辞書にあれば訳し、なければそのまま。
- textarea の中身は変えない。

### 6. 辞書の画面
設定画面（`#mSet`）の「データ」の上に、見出し「訳の辞書」と次を置く。

- 件数の表示：「登録 N 件 ／ 未訳のタグ M 個」。
  - 未訳のタグ＝一覧の全項目（ポジ・ネガ・表情の `text`、シチュエーション・キャラの全チップ。文章は除く）に出てくるタグのうち、辞書にないもの（重複は除く）。
- ボタン「辞書を開く」→ モーダル `#mDict`（`.card.wide`）：
  - 検索欄（英語・日本語のどちらでも絞り込める）。
  - 切り替え「すべて／未訳だけ」。
  - 一覧：英語（等幅）、日本語の入力欄、削除ボタン。未訳のタグは入力欄が空の行として出す。最大200行まで表示し、それ以上は「検索で絞り込んでください」と出す。
  - 入力欄は `change` で保存。
- ボタン「未訳のタグをコピー」：次の文をクリップボードに入れる（タグは1行に1つ、最大300個。超える分は次回）。
  ```
  次の英語のタグ（画像生成AI用）を日本語に訳してください。
  返答は JSON だけにしてください。形は {"英語のタグ":"日本語の訳"} です。
  訳は短い言葉にしてください（例："silver hair":"銀髪"）。

  <タグ1>
  <タグ2>
  …
  ```
  コピー後のトースト：「未訳のタグ N 個をコピーしました。Muse に貼って、返ってきた JSON を『訳を貼り付けて取り込む』に入れてください」
- 「訳を貼り付けて取り込む」：textarea と「取り込む」ボタン。受け付ける形：
  - JSON オブジェクト `{"tag":"訳"}`（前後に ```json などの囲みや説明文が付いていても、最初の `{` から最後の `}` までを取り出して読む）
  - 1行ずつ `tag = 訳` / `tag<TAB>訳` / `tag,訳` / `tag: 訳`
  - ここからの取り込みは、**既存の訳を上書きする**（利用者が意図して入れるため）。
  - 結果のトースト：「訳 N 件を取り込みました（読めなかった行 M）」
- 「辞書ファイルを取り込む」（`.json` / `.csv` / `.tsv` / `.txt`）：上と同じ読み方。CSV は1列目をタグ、日本語（ひらがな・カタカナ・漢字）を含む最初の列を訳とする。
  - 5,000 件を超えるファイルは、**一覧で使っているタグに当たる分だけ**取り込み、その件数を知らせる。
- 「辞書を書き出す」：`prompt-dict-YYYYMMDD-HHMM.json`（`{"tag":"訳"}`）。

### 7. Muse への依頼文
「書き出し」メニュー（`#expMenu`）に「Muse への依頼文をコピー」を追加。押すと、下の文をコピーする（トースト：「Muse への依頼文をコピーしました」）。

```
画像生成AI用のプロンプトを、次の JSON の形で作ってください。返答は JSON だけにしてください。

{
 "v": 3,
 "prompts": [
  {"kind":"sit","name":"シチュエーションの名前（日本語）","folder":"連続したシーンならフォルダ名（任意）","order":1,
   "base":[{"text":"英語のタグ","ja":"日本語の訳"}],
   "neg":[{"text":"英語のタグ","ja":"日本語の訳"}],
   "slots":[[{"text":"キャラ1の状態のタグ","ja":"訳"}]],
   "slotFaces":[[{"text":"キャラ1の表情のタグ","ja":"訳"}]],
   "slotSex":["girl"],
   "slotLines":["キャラ1のセリフ（任意）"]},
  {"kind":"char","name":"キャラの名前","sex":"girl",
   "look":[{"text":"外見のタグ","ja":"訳"}],
   "outfit":[{"text":"服装のタグ","ja":"訳"}]},
  {"kind":"face","name":"表情の名前","text":"smile, blush","ja":"笑顔、赤面"},
  {"kind":"pos","name":"名前","text":"masterpiece","ja":"傑作"},
  {"kind":"neg","name":"名前","text":"lowres","ja":"低解像度"}
 ]
}

決まり：
- タグは1つずつ {"text","ja"} に分けてください。ja は短い日本語にしてください。
- kind は sit（シチュエーション）、char（キャラ）、face（表情）、pos（ポジティブ）、neg（ネガティブ）のどれかです。
- sex は girl / boy / other です。
- slots・slotFaces・slotSex・slotLines は、キャラ1、キャラ2…の順に並べてください。
- 重みを付けるときは "w":1.2 を足してください（0.1〜2.0）。
- 文章で書く部分は "nl":true を足してください。
```

## 守ること（既存の動きを壊さない）

- `index.html` 1ファイルのまま。外部ライブラリを増やさない。
- 既存のコードの書き方に合わせる（`var` と `function`、アロー関数やテンプレート文字列は使わない。HTML に入れる文字列は必ず `esc()` を通す）。
- 既存の保存キーと JSON の形は変えない（追加だけ）。古い JSON（`dict` なし、`ja` なし）も今までどおり読めること。
- 出力（コピーされる文字列）は1文字も変えない。
- スマホ幅（390px）で崩れないこと。ボタンなどの押せる部品は小さくしない。
- 色は既存の変数を使う。点線の下線は `var(--rule2)`。新しい色は増やさない。
- 文言は日本語、敬体、短く。

## 確認すること（実装者が自分で動かして確かめる）

Playwright と Chromium は入っている（`require('playwright')`、`chromium.launch()` にオプション不要）。`file:///…/index.html` を開いて確かめる。テストのスクリプトはリポジトリに入れない。

1. `ja` 付きのチップを含む JSON を取り込むと、辞書に入り、トーストに件数が出る。もう一度取り込むと「すでにある」に数えられる。
2. 組み立てタブのチップが、日本語（主）＋英語（小）になる。訳のないチップは英語＋点線。
3. チップをタップすると小窓が開き、訳を書くと、同じタグを使う他のチップ・一覧の行にも反映される。ドラッグや − ＋ × では小窓が開かない。スマホ（タッチ）の長押し並べ替えが今までどおり動く。
4. 一覧で「銀髪」と検索すると、`silver hair` を含む項目が出る。
5. 「訳を表示」をオン／オフできる。textarea の中身とコピー結果は、辞書の有無で変わらない。
6. 「未訳のタグをコピー」→ 返答を模した JSON（```json の囲み付き）を貼り付けて取り込める。
7. 辞書が JSON バックアップに入り、空の状態から取り込むと復元される。全置換の「元に戻す」で辞書も戻る。
8. 再読み込みしても辞書が残る。
9. `dict` も `ja` もない古い JSON を取り込んでもエラーにならない。
10. ページのエラー（`pageerror`）が出ない。PC幅（1440px）とスマホ幅（390px）のスクリーンショットで崩れがない。

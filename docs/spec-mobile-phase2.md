# 仕様書：スマホの操作（第2回）

設計：Opus 5.5 ／ 実装：Sonnet 5.5。この文書だけを読んで実装できるように書いています。前提は `docs/spec-gloss-phase1.md`（第1回・訳の辞書）が実装済みであること。

## 背景と目的

- 利用者は iPhone でこのアプリ（`index.html` 1ファイル）を使い、出力を NovelAI / PixAI / Muse にコピー＆ペーストします。
- 今の画面は PC 向けの部品が多く、スマホでは押しにくい・場所を取る・スクロールが多い、という問題があります。
  1. チップの − ＋ × が幅約22pxで、指では押し間違える。
  2. 一覧タブの上部（ボタンの行・検索・並べ替え・追加先）で画面の約3割を使う。
  3. NovelAI は入力欄が「ベース」「キャラ1〜n」「除外したい要素」に分かれていて、欄ごとにコピーと貼り付けを繰り返す必要がある。出力欄は組み立てタブの一番下にあり、毎回スクロールが要る。
  4. Muse の返答（JSON）を取り込むには、いったんファイルに保存する必要がある。
- この回では、この4点を直します。

## 1. チップの操作パネル

今の「訳の小窓」（`#glossPop`、`openGloss()`）を、チップの操作もできるパネルに広げます。

### 開き方（今と同じ）
- チップのラベル部分（ボタン以外）を、ドラッグせずにクリック／タップすると開きます。
- ドラッグ（マウスは6px以上、タッチは長押し）を始めたときと、ドラッグ直後のクリックでは開きません（今の `dragEnd` の判定をそのまま使う）。
- 同じチップをもう一度押すと閉じます。外側のクリック、Esc、組み立て欄のスクロールでも閉じます（今と同じ）。

### 中身（上から）
1. **見出し**：チップの主の表示（日本語、なければ英語）を 15px・太字で。その下に英語の全文を等幅・小さく。
2. **重み**：横一列に「−」「重みの値（例：1.20、等幅、中央）」「＋」「1.0 に戻す」。
   - − と ＋ は既存の刻み（`S.cfg.step`）で、範囲 0.1〜2.0（既存の `chipClick` と同じ計算）。
   - ボタンの大きさは **高さ44px以上・幅44px以上**。
   - 押すたびに `renderComp()` と `save()` を呼び、パネルは開いたまま、値の表示を更新する（パネルの位置は動かさない）。
3. **訳**：今の小窓の中身（タグごとの英語・入力欄・Google 翻訳／Danbooru のリンク）をそのまま。
4. **外す**：一番下に、横幅いっぱいの「このチップを外す」（`btn danger`、高さ44px）。押すとチップを外してパネルを閉じる。確認は出さない（今の × と同じ扱い）。

### 置き場所
- **PC（幅721px以上）**：今の小窓と同じく、チップの近くに浮かせる（幅 min(340px, 100vw-16px)）。
- **スマホ（幅720px以下）**：画面下に固定するシート（`left:0; right:0; bottom:0`、上の角だけ丸く、下のタブバーの上に重ねてよい）。高さは中身に合わせ、最大で画面の70%。中身が多いときはシートの中でスクロール。上端に「閉じる」ボタン（右上、44×44px）。シートの外側を少し暗くする（`rgba(28,38,51,.25)`、押すと閉じる）。
- シートが開いている間、入力欄にフォーカスしても閉じないこと（今の `#dock` の scroll での自動クローズは、シート表示中は無効にする）。

### チップ自体のボタン
- **スマホ（幅720px以下）では、チップの − ＋ を非表示**にする（`.wbtn{display:none}`）。重みはパネルで変える。
- × は残すが、押せる範囲を広げる（見た目はそのまま、`.xbtn` に `min-width:32px; min-height:32px` 相当の当たり判定。チップの高さが増えすぎないように、padding ではなく `::before` などで当たり判定を広げてもよい）。
- PC では今のまま（− ＋ × を表示）。

## 2. 一覧タブの上部の整理（スマホのみ、幅720px以下）

PC（幅721px以上）の見た目と動きは変えません。

### 新しい並び
```
┌──────────────────────────────┐
│ [🔍 検索…………………………] [⋯]   │ ← 1行目：検索と「⋯」メニュー
│ すべて ポジ ネガ 表情 シチュ キャラ │ ← 2行目：種別（横スクロール）
│ 追加先：「告白」のベース   [開く] │ ← 3行目：今の追加先（1行）
├──────────────────────────────┤
│ 一覧 …                        │
└──────────────────────────────┘
                          （＋）  ← 新規追加（右下に浮かぶ丸ボタン）
```

- 今の `.barR`（新規追加・取り込み・書き出し・設定・件数）と、`.tools` の並べ替え（`#sort`）・「すべて選択」（`#bSelAll`）は、スマホでは隠す。**要素は消さずに残し**、下の新しい部品から同じ処理を呼ぶ（PC では今のまま使う）。
- **「⋯」メニュー**（`#moreMenu`、既存の `.menu` と同じ作り。ボタンは高さ44px）：
  - 「取り込み（ファイル）」→ `#bImp` と同じ
  - 「貼り付けて取り込む」→ 下の 4 を開く
  - 「書き出し…」→ 今の `#expMenu` を開く（位置は「⋯」の下）
  - 区切り線
  - 並べ替え：4つの選択肢（追加が新しい順／お気に入り優先／使用回数が多い順／表示名順）を、今の値に ✓ を付けて並べる。押すと `#sort` の値を変えて一覧を描き直す。
  - 「表示中をすべて選択」→ `#bSelAll` と同じ
  - 区切り線
  - 「設定」→ `#bSet` と同じ
  - 一番下に件数（「39 件登録」）を小さく。
- **種別の行**（`#kindBar`）：すべて／ポジ／ネガ／表情／シチュ／キャラ の6つ。横スクロール（スクロールバーは隠す）。押すと `S.f.kind` を変えて `render()`。今の値は種別の色で塗る（絞り込みタブの `.kinds` と同じ色の付け方）。絞り込みタブの種別ボタンと**同じ状態**を表示すること（どちらで変えても両方そろう）。
- **追加先の行**（`#tgtbar`）：スマホでは1行に収め、あふれたら `…`。「組み立てを開く」は「開く」に短くする。
- **新規追加の丸ボタン**（`#fabNew`）：直径56px、`var(--pos)` の塗り、白い「＋」、右下に固定（`right:16px; bottom:calc(var(--tabh) + 16px + env(safe-area-inset-bottom))`）。押すと `#bNew` と同じ。`aria-label="新規追加"`。一覧タブ（`#v1`）が表示されているときだけ出す。モーダルやシートが開いているときは隠す。
- トースト（`.toast`）が丸ボタンと重ならないように、スマホでは丸ボタンの上に出す。

### 一覧の行の操作（スマホのみ）
- 行の右の ★ ✎ 🗑 を、スマホでは「⋯」1つ（44×44px）にまとめる。押すと行メニュー（`#rowMenu`）：「お気に入りにする／外す」「編集」「削除」（削除は `danger` の色、確認なしで今と同じ「元に戻す」付きトースト）。フォルダ内のシーンの行は「前へ」「後ろへ」も入れる。
- フォルダ行の ✎（フォルダ名を変更）はそのまま。
- PC では今のまま ★ ✎ 🗑 を並べる。

## 3. 順番コピーのバー（組み立てタブ）

出力欄の場所まで戻らずに、欄ごとのコピーを順番にできるようにします。

### 置き場所
- 組み立てタブの下端に固定（`#v3` の中、`#dock` のスクロールの外）。スマホでは下のタブバーのすぐ上。PC では右の組み立て欄の下端。
- 背景は `var(--sheet)`、上に `1px solid var(--rule)` と軽い影。高さはおよそ 64px。
- 出力が1つもない（すべて空）ときは出さない。

### 中身
```
┌──────────────────────────────────────┐
│ ベース✓  キャラ1✓  キャラ2  ネガ        │ ← 欄の一覧（横スクロール）
│ [ 次をコピー：キャラ2 ]  [最初から]     │
└──────────────────────────────────────┘
```
- 欄の一覧は `compose().boxes` のうち中身があるものを、出力欄と同じ順に並べる。名前は短くする：「ベース」「キャラ1」「キャラ2」…「ネガ」（PixAI では「プロンプト」「ネガ」）。キャラ未選択の欄は名前の後ろに小さく「未選択」。
- コピー済みの欄には ✓ を付け、色を薄くする。
- 「次をコピー：〇〇」（`btn go`、高さ44px、幅いっぱいに近く）：まだコピーしていない最初の欄をコピーし、✓ を付ける。トーストは「〇〇をコピーしました（残り N）」。全部済んだら、ボタンは「すべてコピーしました」（押せない）になる。
- 欄の名前を押すと、その欄だけをコピーして ✓ を付ける。
- 「最初から」：✓ をすべて外す。
- 出力の中身が変わったら（その欄の文字列が前回コピーしたときと違ったら）、その欄の ✓ は自動で外れる。欄ごとに「コピーしたときの文字列」を覚えておき、比べる。
- コピーの処理は既存の `copy(txt,msg)` を使う。コピーする文字列は出力欄（textarea）と1文字も違わないこと。
- この進み具合は保存しない（再読み込みで最初から）。

## 4. 貼り付けて取り込む

Muse の返答をファイルに保存せずに取り込めるようにします。

- 「⋯」メニュー（スマホ）と、PC の「取り込み」ボタンの隣に「貼り付けて取り込む」（PC は `btn`、スマホは「⋯」メニューの項目）。
- 押すとモーダル `#mPaste`（`.card.wide`）：
  - 説明：「Muse の返答（JSON）を貼り付けてください。前後の説明文や ```json の囲みが付いていても読み取れます。」
  - 大きな textarea（高さ 40vh、等幅）。
  - ボタン：「クリップボードから貼り付け」（`navigator.clipboard.readText()` が使えるときだけ出す。失敗したら「貼り付けを許可できませんでした。入力欄を長押しして貼り付けてください」とトースト）、「キャンセル」、「読み取る」（`btn go`）。
- 「読み取る」：
  - 文字列から JSON を取り出す。前後の空白を除き、```json …``` の囲みがあれば中身を使う。それでも読めなければ、最初の `{` または `[` から、最後の `}` または `]` までを取り出して読む。
  - 読めた値は、ファイルの JSON 取り込み（`readFile` の JSON の分岐）と**同じ処理**に渡し、同じ「取り込む項目を選ぶ」画面（`openImport`）を開く。ファイルの分岐の中身を関数に切り出して、両方から呼ぶ形にする。
  - 読めなかったときは、モーダルを閉じずに「JSON として読み取れませんでした。Muse の返答をそのまま貼り付けてください」とトースト。
  - 取り込み画面を開いたら `#mPaste` は閉じる（入力した文字は消す）。

## 守ること（既存の動きを壊さない）

- `index.html` 1ファイルのまま。外部ライブラリを増やさない。
- 既存のコードの書き方に合わせる（`var` と `function`、アロー関数・テンプレート文字列・`let`/`const` は使わない。HTML に入れる文字列は必ず `esc()` を通す）。
- 既存の保存キーと JSON の形は変えない。
- コピーされる文字列（出力欄・まとめてコピー・.txt・順番コピー）は、出力欄の中身と1文字も違わないこと。
- PC（幅721px以上）の一覧タブの見た目と操作は変えない（変えてよいのは、チップの操作パネルの中身、順番コピーのバー、「貼り付けて取り込む」ボタンの追加だけ）。
- 長押しでのチップの並べ替え、PC のドラッグは今のまま動くこと。
- 押せる部品は、スマホで高さ44px以上を目安にする（文中で指定したもの）。
- 色は既存の変数を使う。新しい色は増やさない。
- 文言は日本語、敬体、短く。
- 既存の id と重複しないこと。

## 確認すること（実装者が自分で動かして確かめる）

Playwright と Chromium は入っている（`require('playwright')`、`chromium.launch()` にオプション不要。何もインストールしない）。テストのスクリプトはリポジトリに入れず、スクラッチ用のフォルダに置く。PC（1440×1000）とスマホ（`devices['iPhone 13']`）の両方で確かめ、`pageerror` を集め、スクリーンショットを撮って自分で見る。

1. チップをタップするとパネルが開く。スマホでは画面下のシート、PC ではチップの近く。重みの − ＋ 「1.0 に戻す」で値が変わり、出力にも反映される。「このチップを外す」で外れる。訳の入力と保存も今までどおり。
2. スマホではチップの − ＋ が見えない。× は押せる。PC では − ＋ × が今のまま見えて動く。
3. 長押しの並べ替え（タッチは CDP の `Input.dispatchTouchEvent` で長押し→移動）と PC のドラッグが今までどおり動き、パネルは開かない。
4. スマホの一覧タブで、上部が「検索＋⋯」「種別の行」「追加先の1行」になっている。⋯メニューのすべての項目が動く（取り込み・貼り付けて取り込む・書き出し・並べ替え4種・表示中をすべて選択・設定）。
5. 種別の行と絞り込みタブの種別ボタンが、どちらで変えても同じ状態になる。
6. 右下の丸ボタンで新規追加が開く。一覧タブ以外とモーダル表示中には出ない。
7. スマホの行の「⋯」から、お気に入り・編集・削除（元に戻す付き）・フォルダ内の前へ／後ろへが動く。PC の行は今のまま。
8. 順番コピーのバー：「次をコピー」で欄が順にコピーされ（クリップボードの中身が各出力欄と一致）、✓ が付き、全部済むと押せなくなる。欄の名前で個別コピー、「最初から」で ✓ が外れる。出力を変えると、その欄の ✓ が外れる。PixAI でも動く。出力が空のときはバーが出ない。
9. 貼り付けて取り込む：```json の囲みと前後の説明文が付いた JSON を貼ると、取り込み画面が開き、ファイルからと同じように取り込める。読めない文字列ではトーストが出てモーダルが残る。
10. これまでの機能が壊れていない：取り込みの項目選択、フォルダ、セリフ、キャラ枠の状態・表情、表情から選ぶ、種別の変換、一括削除、まとめてコピー、コピーして開く、訳の辞書。`pageerror` が出ない。PC とスマホのスクリーンショットで崩れがない。
